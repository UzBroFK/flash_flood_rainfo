Serving Model

Produced by the reproducible pipeline: python -m ml.pipeline.run. The serving artifact is a physics-informed soft-voting ensemble; full comparison across all models is reported openly below.

Dataset & Pipeline

Features: SCS-CN runoff (Q = (P−0.2S)²/(P+0.8S)), Antecedent Precipitation Index, moisture-adjusted Curve Number (AMC I/II/III) and Kirpich time of concentration — computed by the same code path used at serving time (no train/serve drift). Stratified train/test split, 5-fold CV, fixed seed 42 for full reproducibility.

All models evaluated on the same 20% stratified test split. Accuracy, precision, recall, F1, ROC-AUC, PR-AUC and Matthews Correlation Coefficient.
